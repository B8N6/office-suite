B8N6

OFFICE SUITE

Self-hosted multi-domain webmail with cloud storage, calendar sharing, and a full admin panel. Single Go binary. No database required.

⬢ View on GitHub ↓ Download v1.0.0 ☰ Install Guide

CORE FEATURES

Built for teams who own their infrastructure
📧
IMAP Mail Client
Full-featured reader & writer with threading, rich compose, scheduled send, filter rules, signatures, attachments up to 25MB.
🔗
Multi-Account
Log into multiple mailboxes. Switch with one click. Unified "All Inboxes" view. Colour-coded avatars per account.
☁️
Cloud Storage
Upload files, share with specific emails, domain-wide, or public links. Per-user quotas. Per-domain caps.
📅
Shared Calendar
Day/week/month views. Share calendars with teammates. Colour-coded events.
💬
Support Tickets
Users open tickets from Settings. Admins reply from the dashboard. Domain-scoped for multi-tenant setups.
🎨
White-Label
Owners customize app name, logo, favicon, and full color palette. Per-domain theme overrides for multi-brand deployments.
🛡️
Role-Based Admin
Two-tier RBAC: owners manage everything, domain admins scoped to assigned domains. Passwordless admin via IMAP ownership.
🌓
Dark + Light
Per-user theme toggle. Each domain can define its own dark and light palettes independently.
⚡
Zero Database
Single Go binary + React SPA + JSON files in data/. No Postgres, no Redis, no setup friction.

QUICK INSTALL

One-shot installer for Ubuntu / Debian
▸ UBUNTU 22.04+ / DEBIAN 11+
# Clone + install with systemd service git clone https://github.com/B8N6/office-suite.git cd office-suite sudo bash deploy-ubuntu.sh # Bootstrap your first owner sudo systemctl edit b8n6-office-suite # add: Environment=B8N6_INITIAL_OWNER_EMAIL=admin@yourdomain.com sudo systemctl restart b8n6-office-suite # Access at http://your-server:8787

TECH STACK

Modern, boring, proven
⬡ BACKEND
Go 1.22 · gorilla/mux · gorilla/sessions · go-imap · net/smtp
Single binary, ~10MB. Starts in milliseconds.
⬡ FRONTEND
React 18 · TypeScript · Vite · Zustand · React Query · TipTap
Served as static assets from the Go binary.
⬡ STORAGE
File-based JSON · MD5-hashed per-user dirs · Atomic writes
Practical for up to ~50k users per instance.
